# Anvil 引擎

> 多格式问答集教学引擎：读第三层 Excel，识别 9 种题型（多选 / 矩阵 / 完形 / 匹配 / 图文 / 持久媒体 / 音频图文…），随机抽题呈现交互练习，产出每题 0/1 的领域评分证据。AUGENBLICK 平台 5 引擎之一。

- 引擎：Anvil（`src/anvil/`）
- 依赖合约：`../../docs/合约.md`（当前 v0.3，草案，待 Znawca 切片跑通后冻结）
- 复用：Znawca 代码为可选参考（可照搬选择/图片/填空题型 UI；矩阵/匹配/音频/多图题型 + 题型分型逻辑为新增）
- 开工前必读：`../../docs/工作约定.md`、`../../docs/GLOSSARY.md`、`../../docs/ARCHITECTURE.md`、`../../docs/边界与验收.md`

## 一句话职责

呈现 9 种交互题型活动（载题 / 乱序选项 / 播放媒体 / 采集作答），理解第三层数据（Excel → 编译为规范化内容 + 题型分型），提交领域评分证据（每题 0/1）。不碰进度显示、对错裁决、掌握度、调度、账号支付。

## 目录

- `src/` —— 引擎代码（分层职责见 `src/README.md`：`core` 领域逻辑 / `ui` 答题界面 / `adapter` 合约适配器 / `datasource` 数据源）
- `tests/` —— 测试（`contract` 合约一致性测试规范见 `tests/contract/README.md`）
- `docs/` —— 本引擎治理：`边界.md`、`验收.md`、`待确认.md`、`adr/`（引擎内部 ADR 规范见 `docs/adr/README.md`）
- `进度.md` —— 本引擎详细进度日志（append-only）

## 治理约定

- 全局契约（合约 / 架构 / 术语表 / 工作约定 / 全局进度）唯一放根 `docs/`，本引擎**只引用、不复制**。
- 本引擎内部决策写 `docs/adr/`；跨引擎 / 需客户拍板的决策回报规划总控，由总控写根 `docs/adr/` 或 `docs/OPEN-QUESTIONS.md`。
- 本引擎状态变化只回报总控一句「Anvil：状态 A→B，阻塞 C」，由总控更新根 `docs/进度.md` 仪表盘那一行（单向同步，不自动、不双向）。
