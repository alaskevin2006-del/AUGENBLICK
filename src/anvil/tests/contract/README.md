# 合约一致性测试

> 验证 Anvil 适配器对 `../../../docs/合约.md` v0.3 的实现是否一致，是全项目「统一合约通过」验收的前提（`../../../docs/边界与验收.md`）。

## 要测什么

| 合约 | 验证点 |
|---|---|
| 内容编译 | `capabilities` 声明 9 题型；`parse` 读编译产物；`validate` 产出单元格级错误（不阻断加载）；`compile` 生成稳定 ID + 资产清单；`estimateItemCount` 可提前确定；`migrate` 兼容旧自动检测 |
| 运行时 | 四事件 `activityReady / itemStarted / itemResolved / activityFinished` 字段完整；每事件带 `eventId` + 顺序号 + 时间戳（幂等重放）；`score` 归一 0-1 |
| UI 宿主 | 面向 Activity Host 挂载接口（非 iframe）；主题 / 尺寸 / 焦点 / 键盘 / RTL / 暂停 / 退出确认由 Host 统一 |

## 组织

- 一个题型一个用例文件，9 题型逐一验证「分型 → 渲染 → 作答 → 评分证据」。
- 重点回归：
  - 题型分型误判率对齐全局验收 `< 0.5%`；
  - 选项乱序（使用编排器随机种子，结果可追溯）；
  - 校验降级（缺媒体 / 结构不符的题跳过，不阻断整课加载）。
