# ADR-0004: Excel = 交换格式，运行时读不可变 Course Version

- 状态：已接受
- 日期：2026-08-25
- 决策人：恺欣

## 背景

原需求让 XLSX/文件夹名直接驱动运行时。但文件名/语言后缀/文件夹名表达身份脆弱，且运行时直接读源文件无法保证版本与回滚。

## 决策

保留 Excel，但定位为「批量创作与交换格式」。内容流水线把它编译为**不可变 Course Version**（规范化内容 + 资产清单），运行时只读编译产物。课程、单元、活动、题目、概念、素材全部使用稳定 ID；文件名仅作显示名或导入线索。

## 理由

稳定 ID + 不可变版本支持版本比较、回滚、内容影响分析，也符合「发布中的版本不可原地覆盖」验收项。

## 影响面

- 内容流水线：新增编译步骤（parse → validate → compile）。
- 引擎数据源：不再直接读源文件，改读编译产物。

## 后果

- 利：可追溯、可回滚、多语言/多版本素材复用。
- 弊：多一层编译，需维护编译缓存。
- 回看点：Anvil 旧 Excel 自动检测题型需保留兼容，新模板改显式题型。
