# ADR-0015: Additional engine pilot integration

2026-10-19. User explicitly requested staged/branch implementation of the remaining documented engines without third-party APIs. This authorizes the integration work previously gated on a frozen contract; it does not freeze or declare acceptance of the entire platform baseline.

Adopt the interfaces and staged scope in `../superpowers/specs/2026-10-19-additional-engines-design.md`. New engine ZIPs identify their engine via course.json; legacy Znawca ZIPs remain unchanged. Server-only solutions and incremental visual interactions extend the existing authoritative runtime. Structured answers remain encoded in the existing string field, preserving database compatibility.

Anvil cloze/matching score whole questions 0/1; matrix subquestions and persistent-set prompts are independent questions. Ekspert dimensions are named selected axes with mean aggregation; atlas is learning reference. Sokole evaluates pixels and returns only permitted hit overlays; explicit advance retains existing platform interaction. Missing translations fail import/selection explicitly rather than silently skipping required work.

Companion's local acoustic diagnostics are experimental and are not certified phoneme accuracy. Formal pronunciation tests are blocked until model/corpus calibration, while script/recording practice can be implemented and verified independently. Open question #2 remains open. Direct remains reserved.
