# Companion 边界

## 做什么

- 读第三层脚本（Excel，A–Q 列，一行一条指令），顺序执行：应用暂停 → 识别动作列 → 执行动作（播音频 / 语音采集）→ 处理显示文本 → 进下一行（COMPANION §7）。
- 播放音频：母语/目标语引导、四角色对话音频（E/G/J/L/N/P 列）。
- 采集学习者语音并做发音评估：频谱叠加（绿=吻合/红=偏差）、音高曲线（线粗细=音量）、节奏分割（参考在上/学习者在下），智能对比容忍迟疑/停顿/轻微结巴（COMPANION §4 H 列）。
- 处理显示文本 Q 列：`[bold]`/`[red]` 等标签、`*` 续行、`WIPE CLEAN` 清屏、可点击回放、checkpoint 起播时重建显示状态（COMPANION §4 Q 列）。
- 产出领域评分证据：`score 0–1` + `dimensions[]`（音素·节奏·语调）。
- 末行执行完显示「Click to continue」，等学习者按下后交还控制权（COMPANION §7）。

## 不做什么

- 不做上层导航：checkpoint 调度、单元排序、课程管理（编排器 / 平台腿职责）。
- 不做进度追踪、掌握度、错题、间隔复习（Learning State 职责）。
- 不做脚本创作工具、音频生成、TTS、学习者进度分析（COMPANION §10）。
- 不做统一判分裁决（平台统一答案求值管线职责，ADR-0005；引擎只提交评分证据）。
- 不管理媒体存储 / 分发（对象存储 + 签名 URL，ADR-0008）。
- 不做离线 / PWA（V1 纯 Web，全局红线）。

## 内容范围 / 第三层数据结构

第三层 = Companion 私有脚本，对编排器**不透明**，仅暴露：package/checkpoint、itemCount、声音版本（`_M/_F`）约定（ARCHITECTURE 四、AUGENBLICK §3.4）。

列定义（COMPANION §4）：

| 列 | 含义 |
|---|---|
| A | Notes（设计者备注，运行时忽略） |
| B | Checkpoint（整数，导航锚点） |
| C | Pause（秒，行前静默；空=0） |
| D | 母语引导文本（参考，不播音） |
| E | 母语引导音频 |
| F | 目标语引导文本 |
| G | 目标语引导音频 |
| H | 语音输入标记（`Y`=采集语音：3 秒内起说 + 1.5× 参考音频时长上限） |
| I / J | 男 1 文本 / 音频 |
| K / L | 女 1 文本 / 音频 |
| M / N | 男 2 文本 / 音频 |
| O / P | 女 2 文本 / 音频 |
| Q | 显示文本（标签、`*` 续行、`WIPE CLEAN`、点击回放） |

硬规则：E/G/J/L/N/P 音频列**每行互斥，最多一个**（COMPANION §5）；四角色槽位固定上限（男 1/女 1/男 2/女 2，§6）。

## 与全局的关系

- 遵守 `docs/合约.md` v0.3，只实现、不复制。
