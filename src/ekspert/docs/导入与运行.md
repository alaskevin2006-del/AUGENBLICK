# Ekspert 试运行格式

ZIP 根目录放 `course.json`、`data.json` 和图片，或将这些文件放在同一个子文件夹。可直接压缩 `templates/shapes/` 验证上传、发布、试学、历史、困难内容。

`course.json` 指定 `engine: ekspert`、`title`、`languageCode`、`source: data.json`。

`data.json` 包含 `module.axes` 与 `records`。轴字段为 `id/name/type/values`；type 支持 enum、numeric、boolean。enum 必须列出合法值，optional 轴允许个别记录缺失。记录需要稳定 `id`、`axes`，可带 `name/media/features`。`media.svg` 或 `media.img` 指向包内图片；SVG 经平台安全校验后提供。新增模块无需改代码。

每条记录生成逐轴问题及多轴问题。enum 最多六个选项，优先加入 `confuse_with`（也接受 `features.confuse_with`）中对应合法值，再补足；选项顺序稳定打乱。numeric 使用数字输入，boolean 使用是/否。每轴等权，得分为正确轴比例；掌握须全部轴正确。源答案与 private solution 不进入实时题面。

图鉴通过课程内学习参考接口单独读取，可按轴筛选、展开特征；其内容不用于提交分数。既有历史、困难内容及开发者预览隔离由平台负责。比较、决策树、自适应、田野模式不在本次试运行范围。

提供的几何示例是功能验收素材，不代表已完成专业足迹 50 种或牙齿 5 物种内容生产；后者仍需经专业核验的素材及标注。
