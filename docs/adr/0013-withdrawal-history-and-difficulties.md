# ADR-0013：退课、个人历史与困难内容

- 日期：2026-10-19
- 状态：按用户明确要求实施
- 范围：在现有试点补齐退课、历史、困难内容，保持其他页面与学习规则。

## 退课

普通用户可在「我的课程」确认退课。服务端移除加入关系，将该用户此课程尚未关闭的正式活动标记为取消，保留所有答题、事件、历史与正式测试提交记录。重新选课不会重置已提交测试的限制。开发者不加入课程，继续使用预览。

退课与启动、作答、提交使用兼容的数据库锁顺序，避免退课后继续写入。已下架但仍加入的课程也可通过接口退课。无加入关系或个人活动记录的未发布课程返回 404，不向无关用户透露草稿信息；因此无任何活动记录的草稿退课后，再次请求可能返回 404，状态仍保持已退课。

## 历史

顶部「历史」与课程内入口展示本人已完成、已跳过及已取消的活动，包含时间、模式、状态、进度与适用的测试成绩，提供分页与只读答题明细。退课或课程下架后仍能读取本人历史。明细只展示实际作答记录，不返回未作答题目的答案或完整题库。

历史读取与正在进行的活动权限分开实现，不放宽现有启动、作答或提交权限。普通用户只读自己的正式记录，开发者只读自己的预览记录；双方共用展示界面。

## 困难内容

服务端根据现有活动记录重建困难列表，按「用户 + 课程版本 + 对象」归集，沿用 ZNAWCA 的对象级规则。一次已完成活动中该对象任何作答不完全正确，就记为困难并重置恢复计数；该对象之后在两次已完成活动中所有作答均完全正确，才移出困难列表。未出现该对象的活动不计数；已取消活动不计入；已跳过活动可记入错误，但不能推进恢复。

新入口列出困难对象及课程，可进入原有课程设置进行集中练习。`difficultOnly` 由服务端过滤题库并计算可用题量，与现有题型、方向、分类条件叠加。默认关闭，不改变原有抽题规则。零题时禁止开始，但可取消勾选恢复普通练习。已退课或下架课程保留困难记录，开始练习仍要求课程已发布且用户已加入；预览按开发者权限独立处理。

本次不增加本地权威学习状态、自动间隔复习或清空历史按钮，不修改上传、发布、语言、计分及其他引擎。
