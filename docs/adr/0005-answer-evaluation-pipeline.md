# ADR-0005: 统一答案求值管线

- 状态：已接受
- 日期：2026-08-25
- 决策人：恺欣

## 背景

各引擎各自判题会导致格式型误判（大小写、全半角、上下标等）。用户反馈已证明 `H₂O/H2O` 上下标误判、校验误报会直接破坏体验。

## 决策

建立**共享答案求值管线**：Unicode、大小写、空白、全半角标点规范化；按题配置 `H₂O/H2O` 等兼容规则；明确区分「必须全部包含」「可接受替代」「顺序无关列表」；同义词由作者确认，AI 只建议、不擅自放宽正式评分。

## 理由

统一判分是「逻辑全走 API」的落地，也是「格式型答案误判率 < 0.5%」验收项的前提。

## 影响面

- 平台后端：单一判分服务，各引擎不再自建判题。
- 各引擎：提交领域评分证据（dimensions），由平台统一裁决对错。

## 后果

- 利：判分一致、可追溯、易调优。
- 弊：需覆盖各引擎题型差异（填空/匹配/多轴/掩膜）。
- 回看点：测试采用固定蓝图，不得自动提高历史错题出现率；自适应仅用于练习。
