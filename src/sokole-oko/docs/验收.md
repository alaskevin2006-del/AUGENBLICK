# Sokole Oko 验收标准

## 完成标准（可量化）

- 通过合约一致性测试（`tests/contract`），四事件字段完整、可幂等重放（`eventId` / 顺序号 / 时间戳）。
- 端到端跑通一节代表课：载图 → 点击 → 命中判定 → 评分证据 → 事件回传。
- 评分归一验证：`score` = 命中区域数 ÷ 总区域数（例：3/4 = 0.75）。
- 动态容差：小目标（黑像素占比低）放大命中半径；公式经测试调优（`requirements/SOKOLE OKO.md:Click Detection`）。
- 掩膜命中精度：格式型误判率对齐全局 `< 0.5%`（`docs/边界与验收.md`）。
- 多语言：EN / PL / AR / RU / ZH-S / ZH-T 文本解析正确；AR 等 RTL 布局由宿主处理。
