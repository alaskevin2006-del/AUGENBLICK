# ADR-0006: Polyglot / Savant 双品牌多站点部署

- 状态：已接受
- 日期：2026-08-25
- 决策人：恺欣

## 背景

AUGENBLICK 双品牌（Polyglot / Savant）= 同一软件的精确克隆，仅 logo 不同，分别部署在不同域名。Polyglot 教语言、Savant 教其他学科（地质/生物等）；内容不同，但引擎与格式完全相同。

## 决策

**单代码库、多站点部署**：同一容器镜像部署两次，通过运行时配置区分域名、logo、站点代码、存储前缀。前端品牌配置**不编译进 Vite 包**（用 CSS Variables + 运行时配置），两个站点共用同一份镜像。

## 理由

避免为两个品牌分叉代码库；一处改、两处生效；迁移/扩容只需多起一个实例。

## 影响面

- 前端：品牌（logo/颜色/站点名）走运行时注入，不进构建产物。
- 后端：以 `site_code` 隔离内容目录与存储前缀。
- 部署：Compose 里 Polyglot/Savant 各一份服务，指向同一镜像。

## 后果

- 利：单代码库、零分叉、可复现。
- 弊：品牌配置必须以运行时变量管理，杜绝硬编码进代码。
- 回看点：账户是否跨品牌互通，仍待定（见 OPEN-QUESTIONS）。
