# Sokole Oko 边界

> 本引擎边界由本引擎维护；跨引擎冲突报规划总控。

## 做什么

- **呈现视觉识别活动**：加载图片、渲染掩膜覆盖层、捕获点击坐标、像素级命中判定（含动态容差膨胀）。
- **理解第三层专业数据**：解析课程文件夹（图片 / 掩膜 / 文本）→ 编译为规范化内容，含：
  - 文件名分组：`CourseName Number - description` → 课程 + 难度开关；
  - 两题型判定：Knowledge（文本名 = 掩膜名）/ Observation（文本名 = 图片名）；
  - 多语言文本解析（每行 `语言码: 问题`）。
- **提交领域评分证据**：`dimensions[]`（各区域命中/未命中）、`score`（found/total）、作答耗时、错误类型。
- **实现三份合约适配器**：内容编译（`parse`/`validate`/`compile`/`estimateItemCount`）+ 运行时四事件 + UI 宿主挂载。

## 不做什么

| 事项 | 归属 |
|---|---|
| 进度条 / 导航 / RTL / 界面语言切换外壳 | Shell |
| 对错最终裁决 / 掌握度 / 错题加权 / 间隔复习 | 统一判分管线 + Learning State |
| 调度 / 随机种子 / 题集固定 / 中断恢复 | 编排器 |
| 账号 / 支付 / 权限 / 课程目录 | 平台 |
| 内容上传 / 发布 / 回滚 | Course Studio / 内容流水线 |
| 离线 / 桌面版 | V1 纯 Web，后置原生 App |

## 内容范围 / 第三层数据结构

原始需求（`requirements/SOKOLE OKO.md`）的第三层数据：

| 类型 | 命名约定 |
|---|---|
| 课程文件夹 | `CourseName Number - description`（含 Number 则分组为多难度课程） |
| 图片 | `courseidNN.ext`（PNG/JPG/BMP/WEBP） |
| 掩膜 | `image--answerN.png`（PNG、与图片同尺寸、纯黑白；黑 = 正确区域） |
| 文本 | `image.txt`（Observation）或 `image--answerN.txt`（Knowledge），每行 `语言码: 问题` |
| 语言码 | EN / PL / AR / RU / ZH-S / ZH-T |

编译约定（遵循 `docs/合约.md` 内容编译合约 + ADR-0004 / ADR-0008）：

- 文件名仅作导入线索，编译后统一转稳定 ID；
- 掩膜 / 图片进对象存储，结构进数据库，运行时只读不可变 Course Version。

## 与全局的关系

- 遵守 `docs/合约.md` v0.3，只实现、不复制。
- 复用度约 20%，从零新写。
- 合约冻结前只准备合约无关内容（教学内容 / 掩膜素材），不写适配器（`docs/工作约定.md` 红线 2）。
