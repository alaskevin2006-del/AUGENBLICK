# Ekspert 验收标准

## 完成标准（可量化）

- 通过合约一致性测试（`tests/contract`），四事件字段完整、可幂等重放（`eventId` / 顺序号 / 时间戳）。
- 端到端跑通一节代表课：Atlas → 单轴 quiz → 多轴 quiz → 评分证据（`dimensions[]`）→ 事件回传。
- 评分归一验证：`score` = 各轴命中比例（如 4 轴对 3 = 0.75）；`dimensions[]` 逐轴输出判定结果。
- 多轴判定：各轴独立评分，干扰项优先取 `confuse_with` 字段（`requirements/EKSPERT.md §4.2`）。
- V1 范围 = Phase 1：单轴+多轴 quiz、Atlas 过滤、tracking（50 足迹）+ teeth（5 物种）、基础统计、SVG（`docs/待确认清单.md` Q15）。
