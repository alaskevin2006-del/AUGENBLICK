# ADR-0014：课程内导航、历史及困难内容归属

- 日期：2026-10-19
- 状态：按用户明确反馈实施
- 依据：历史和困难内容应对应具体课程，课程内流程参考桌面 ZNAWCA；其他规则保持。

## 课程内流程

参考桌面 ZNAWCA 的 `renderer/app/navigation.tsx`、`features/history/HistoryList.tsx`、`ReplayView.tsx` 以及当前产品基线，进入课程后固定显示课程名称及「学习、测试、学习历史、测试历史、困难内容」导航。移除网站顶栏的跨课程历史、困难入口；记录不会混在全局列表中。学习/测试切换复用原有设置与活动，无新计分或重考规则。

学习历史和测试历史分别按服务端模式筛选、分页，数量只统计当前用户、当前课程版本及对应正式/预览身份的记录。历史详情使用当时的题目、选项、提交答案及反馈，只读逐题回看，可前后切换、选择题号、返回本课程列表，不重新生成题目或提交作答。困难内容显示当前课程对象及恢复次数，集中练习仍走这门课的设置与服务端筛选。

新课程路由为 `#/course/{encodedId}/{tab}`，tab 为 learn/test/learning-history/test-history/difficulties。旧课程根链接继续进入学习；带课程的旧历史、困难链接转换到相应课程页。没有课程的旧全局链接回到所属角色课程列表，不触发跨课程记录请求。

## 退课及下架后的历史

「我的课程」提供按课程排列的过往课程入口，只列不在当前课程卡片中但本人已有关闭活动的课程。进入后仍使用课程内的历史与困难栏目；未重新选课或下架时学习、测试入口不可用。记录读取权限不等于继续学习权限。

新增安全的课程记录概况接口，使空历史页、退课和下架课程仍能显示正确课程名称、各项计数及可学习状态，不依赖作者载荷或设置接口授权。无本人加入/活动关系的未发布课程不可读取。

## 不变范围

本次桌面参考聚焦课程组织、分开历史和只读回看。既有分批抽题、判分、测试一次提交、困难恢复、发布/下架、上传及五语言保持。不会把桌面文件系统、离线存储或清空本地数据功能搬入 Web；权威数据仍在服务器。
