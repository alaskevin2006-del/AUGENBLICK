# Sokole Oko 试运行格式

ZIP 根目录 `course.json` 指定 `engine: sokole-oko`、`title`、`languageCode`。保留平台既有学习/测试、题量、历史、困难内容和开发者试学逻辑。

不指定 source 时按旧格式读取同目录素材：`image.png`、`image--target1.png` 和题干 txt。图片支持 PNG/JPG/JPEG/BMP/WEBP；mask 必须同尺寸、完全不透明、纯黑白 PNG，黑色为命中区。`image--target1.txt` 为单点知识题；`image.txt` 为多点观察题。txt 每行 `EN: Question` 或 `ZH-S: 问题`，支持英文语言全称及 EN/PL/AR/RU/ZH-S/ZH-T。所选语言缺译明确报错，不静默跳题。

也可指定 `source: questions.json`，内容为 `{"questions":[{"id":"one","type":"observation","image":"scene.png","masks":["scene--left1.png","scene--right1.png"],"question":"找到所有目标"}]}`。题干也可使用 `translations:{"zh":"...","en":"..."}`。

每次点击单独提交归一化坐标，服务器检查 mask。同一目标重复点击不加分；重叠区域先匹配排列最前的未命中目标；第一处误点结束。知识题误点显示目标红色，观察题误点只让整图变红，未找到目标不暴露。观察题按已找到目标/总目标给部分分，全部找到才算掌握。沿用平台明确点击下一题。

容差半径固定在编译版本内：`min(12, round(min(width,height) * min(0.025, 0.002/sqrt(blackRatio))))`，以像素中心的欧氏距离判断。上限 12 像素；可通过后续版本及验收数据调优。mask 保存在服务端私有载荷，公开存储只包含原图；反馈仅包含允许公开的区域透明覆盖图。

点击图像或使用方向键移动光标、Enter/空格点选；Shift 加快移动。坐标依据实际显示图像尺寸计算。单张图片限制 400 万像素，每题最多 50 个目标、500 次点选；拒绝无黑像素、灰度边缘或透明 mask。

示例生成脚本 `templates/create_demo.py` 生成可直接打包的课程；只包含原创几何示意图，不使用第三方服务。难度按独立导入版本处理，尚未实现跨文件夹名称推断与合并。
