# ADR-0011：开发者独立页面、草稿预览与用户选课

- 日期：2026-10-19
- 状态：按用户批准的精简原型实施
- 来源：用户要求开发者与普通用户页面分离、发布前试学、选择课程与个人课程橱窗；随后明确删除宣传及无需求页面，批准 v2 并要求保留语言切换、修复压缩包上传。

## 本次范围

开发者登录后进入独立课程管理页：上传、课程名称与状态、学习/测试预览、发布。用户登录后进入选择课程，可加入“我的课程”，从个人课程列表开始学习或测试。保持中文、英语、波兰语、俄语、阿拉伯语及 RTL；不增加素材库、预览历史、设置、宣传页或虚构统计。

上传产生不可变草稿版本，默认不发布。开发者试学使用同一引擎和评分逻辑，Session 标记 is_preview，与普通学习记录、测试提交限制隔离；预览可重复。发布为显式幂等操作。用户目录仅展示已发布课程，必须先加入个人课程再开始正式活动。后端在每个会话操作处检查权限，而非只隐藏按钮。

迁移保留先前已公开课程；已存在的普通用户学习关系补入个人课程；旧开发者会话转为预览，避免污染正式记录。

## 上传修复

实际失败记录为 Nginx 413，multipart 请求 299037394 字节，匹配桌面 Płaga.zip 的 299037192 字节。原 ZIP 200 MiB / Nginx 201 MiB 上限不足。调整为 ZIP 512 MiB、Nginx 513 MiB（含表单开销）、解压最多 2 GiB 和 20000 个文件；保留越界路径、符号链接、加密文件校验。前端提前检测大小、展示上传和处理状态及可理解的错误，支持重试。文件由磁盘临时文件承载，不整包驻内存。多工作簿导入数据库事务保证失败不出现半套课程；损坏工作簿返回导入错误。

本次仍是 Znawca 试点；三级编排、其他引擎、完整课程创作编辑器不因本次页面调整而宣称完成。
