# Anvil 边界

> 本引擎边界由本引擎维护；跨引擎冲突报规划总控。

## 基线（既定前提，开工前必须认账）

1. **定位**：Anvil 是 AUGENBLICK 平台的一个教学引擎，**核心职责 = 处理课程数据**：读第三层 Excel → 题型分型 → 编译为规范化内容 → 呈现交互练习 → 产出每题 0/1 的领域评分证据。

2. **不负责（六项，全部归平台腿）**：

   | 事项 | 归属 |
   |---|---|
   | 账户 / 认证 / 支付 | Shell / 平台 |
   | 进度 / 错题 / 间隔复习 | Learning State |
   | 编排调度 / 随机种子 | 编排器 |
   | 导航 / 进度条 / 语言 / RTL | Shell |
   | 内容导入 / 编译 / 版本 | 内容流水线 |
   | 判分裁决 | 统一答案求值管线 |

3. **文档优先级**（冲突时以高者为准，低者让位不覆盖）：

   | 优先级 | 文档 | 性质 |
   |---|---|---|
   | ① 最高 | `docs/` 治理文档（合约 / ARCHITECTURE / ADR / 边界与验收 / GLOSSARY / OPEN-QUESTIONS / 工作约定） | 工程定稿，最终真相源 |
   | ② | `requirements/AUGENBLICK.md` + `AUGENBLICK补充说明.docx` | 平台总纲 |
   | ③ | `requirements/Anvil补充说明.docx` | Anvil 专项补充 |
   | ④ 最低 | `requirements/Anvil.md` | Anvil 原始方案（含平台化前过时内容） |

4. **需求文档过时内容不改**：`Anvil.md` 里的桌面版、独立账户 / 支付、进度回收池、session timer 等属平台化前内容，**保留原样不改**，仅按优先级让位。开发只认治理文档 + 平台文档。

5. **复用 Znawca = 可选参考**：Znawca 代码可照搬可用部分，**非强制复用**；是否复用按实现时需要决定，不把「复用度」当硬约束。

6. **三份合约 v0.3 + 三条架构红线**（逻辑全走 API / 合约唯一不复制 / V1 纯 Web）+ 技术栈（React+TS+Vite / Django / PG17 / S3 / Docker Compose，ADR-0007）。

## 做什么

- **呈现 9 种交互题型**：多选 / 矩阵多子题 / 完形选择 / 完形填空 / 匹配 / 图文选择 / 持久媒体集 / 音频+图文（题型分型规则由本引擎内部 ADR 定稿，见 `docs/待确认.md` B1/B3）。
- **理解第三层专业数据**：解析 Anvil Excel → 题型分型 → 编译为规范化内容（稳定 ID + 资产清单）。
- **提交领域评分证据**：每题 0/1 对错（`score`）+ `attemptNumber` / 作答耗时 / 错误类型。
- **实现三份合约适配器**：内容编译（`capabilities/parse/validate/compile/estimateItemCount/migrate`）+ 运行时四事件 + UI 宿主挂载。

## 内容范围 / 第三层数据结构

第三层 = Anvil 私有 Excel，对编排器**不透明**，仅暴露：package、itemCount（ARCHITECTURE 四、AUGENBLICK §3.4）。

Excel 格式分工（2026-08-25 定）：

- **通用格式约定由 AUGENBLICK 平台统一规定**（跨引擎，回报规划总控 / 进平台级文档）：首行表头、从第 2 行读、难度列、题型列、内容单元媒体判定等通用要素。
- **Anvil 只自定题型级列语义**（写本引擎内部 ADR）：9 题型的槽位定义、cloze 括号语法、matching 分隔符等。

既定方向（依据优先级 ③ `Anvil补充说明.docx ②`，作为平台统一规定的输入）：

- **难度列**（1/2/3…，仅作题目属性，不做递进排序）；
- **第 1 行 = 列标题**（供编辑者参考），软件从**第 2 行**起读；
- **内容单元通用规则**（`Anvil补充说明.docx ①`）：任意题型的内容都可是文本 / 图片 / 音频 / 视频（取决于单元格是否含扩展名）。

> 注：上述改动使 `Anvil.md §4` 的「9 题型自动检测列布局」失效；通用格式约定待平台统一，题型级语义待本引擎 ADR（`docs/待确认.md` B1/B3），不阻塞开工。

编译约定（遵循 `docs/合约.md` 内容编译合约 + ADR-0004/0008）：

- 文件名仅作导入线索，编译后统一转稳定 ID；
- 媒体进对象存储，结构进数据库，运行时只读不可变 Course Version。

## 与全局的关系

- 遵守 `docs/合约.md` v0.3，只实现、不复制。
- Znawca 代码为**可选参考**（可照搬选择/图片/填空题型 UI、会话框架），矩阵/匹配/音频/多图题型 + 题型分型逻辑为新增。
- 合约冻结前只准备合约无关内容（题型数据 / 代表课素材），不写适配器（`docs/工作约定.md` 红线 2）。
