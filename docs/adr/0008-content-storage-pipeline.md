# ADR-0008: 内容存放混合模式 + 内容流水线

- 状态：已接受
- 日期：2026-08-25
- 决策人：恺欣

## 背景

不可变 Course Version（ADR-0004）需要明确「结构状态 vs 文件」各存哪、以及内容如何从 ZIP 流到发布版本。

## 决策

**数据库管结构与状态，对象存储管文件。**

| 内容 | 存放 |
|---|---|
| 用户/权限/课程目录/单元/活动/注册关系 | PostgreSQL 关系表 |
| 不可变 Course Version、稳定 ID、编译后活动载荷 | PostgreSQL（引擎私有部分用 JSONB） |
| 答题事件/评分/错题/恢复点/验证报告/审计日志 | PostgreSQL |
| 原始 ZIP/XLSX、图片、音频、视频、SVG、掩膜 | 对象存储 |
| 媒体转码结果、缩略图、编译清单快照 | 对象存储 |
| 临时解析文件 | 后台任务临时目录，结束即清 |
| 缓存与任务状态 | Redis（非数据真相源） |

对象表只存 `bucket、object_key、checksum、mime、size`，不存写死的完整网址。

## 内容流水线

1. 管理员把 Excel + 媒体打成 ZIP，分片上传直入对象存储。
2. 保存原始包 + SHA-256 + 上传版本，永不原地覆盖。
3. 后台任务执行 `解析 → 单元格级校验 → 编译 → 生成资产清单`。
4. 发布时生成新 `course_version_id`，数据库原子切换「当前发布版本」指针。
5. 学习会话固定绑定一个课程版本；新上传不影响在学学员。
6. 媒体走短期签名 URL/CDN，付费课程 Bucket 不公开。

## 理由

- 稳定 ID + 版本指针 → 可回滚、可追溯、会话不串版。
- 不写死 URL → 换存储只改配置。
- COS 走 S3 兼容子集（上传/下载/HEAD/分片/签名 URL），双端跑兼容测试。

## 后果

- 利：结构与文件解耦，迁移/回滚安全。
- 弊：多一层编译 + 缓存维护。
- 回看点：COS S3 兼容非 100%，需对 COS 与客户侧存储跑兼容测试。
