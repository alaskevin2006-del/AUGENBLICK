# Anvil question format and scoring

2026-10-19. Implements platform ADR-0015 and contract extension. Anvil is a Web engine in the shared platform; no external service is called.

ZIP root contains course.json, course.xlsx and relative media assets. Manifest: `{"engine":"anvil","title":"Course","languageCode":"en","source":"course.xlsx","legacy":false}`. Workbook first row is `difficulty | type | stimulus | prompt | option1 | option2 | …`; rows begin at 2. Explicit numeric types 1–9 preserve the original numbering. Difficulty is a nonnegative integer property, not an ordering rule. Correct choice is the first authored option; compiled option IDs are cryptographically random tokens and positions shuffled. Content item IDs remain stable; answer tokens do not encode source row/column or correct position. Source coordinates stay in author diagnostics only.

Type 1: stimulus and choices. Type 2: stimulus/options header followed by rows with empty A/B/C, subquestion D and exact correct header label E. Type 3: stimulus, explicit D question and E+ options; empty A/B/C continuation rows retain stimulus. Type 4: bracket selection in C. Type 5: mixed or typed bracket in C, tilde prefix means typing. Type 6: E+ pairs/triplets separated with asterisks, C=`*`. Type 7: question in C, choices E+. Type 8: C=`*`, E+ `label * media` entries. Type 9: stimulus C, question D, choices E+.

Content cells may be text or relative media filenames; image, audio and browser video are rendered through public hashed assets. `.avi` is not supported by this pilot and must be converted before import. Optional cell-coordinate MP3 narration sits at ZIP root, e.g. `D4.mp3`. Cloze selection choices support content units; typed blanks accept text. Matching uses two or three independently scrambled columns with unique values per column. Repeated identical parts are rejected because their mappings would be ambiguous.

Matrix subquestions and persistent media prompts are separate items. Cloze passages and matching sets are whole items: score 1 only if every slot is right, otherwise 0; dimensions report slot outcomes. In `[~American;Kenyan]` only `American` is correct. Normalization uses the platform Unicode/width/case/whitespace function; semantically unrelated alternatives are never accepted. Engine does not define its own recovery or mastery policy.

`legacy:true` opts into original A stimulus / B question / C+ choices format; row 1 remains a header. No implicit migration detection runs on existing Znawca content. Detection prefers asterisk media/matching, cloze, media image choices, matrix continuation, explicit media question, media identification, then text image choices. Author errors include cells and skip bad rows; no valid item rejects the upload. Unknown/malformed format is never silently treated as a valid question.

Compilation emits platform items/questions; `solution` is private. Live `interaction` contains rendering content and opaque choices only. Structured cloze/matching answers are JSON objects encoded in the existing answer string. Server validates exact key sets and values. Root integration owns per-session and subsequent presentation shuffle, fixed assessment bank, authenticated media, preview, records and read-only replay.
