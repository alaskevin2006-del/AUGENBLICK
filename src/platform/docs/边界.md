# Platform 边界

> 平台（学习操作系统）边界，由规划总控维护。共性约束见 `../../docs/baseline/README.md` + `platform.md`，不重复。

## 定位

AUGENBLICK 学习操作系统 = Shell + 编排器 + Web 后端（API/DB/认证/支付桩）+ 内容流水线 + Course Studio/后台。学习者看课程/目标/进度/反馈；开发者看结构/校验/预览/发布。

## 不做什么

- 各引擎领域逻辑与第三层数据格式（对编排器不透明，仅暴露 package/checkpoint/itemCount/声音版本）。
- 判分裁决由统一求值管线做，引擎只交领域证据。

## 与全局关系

五方状态归属：平台拥有 Shell / 编排器 / Learning State / 内容流水线；引擎拥有呈现 + 领域评分证据。
