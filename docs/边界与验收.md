# 产品边界与验收标准

> 全局形态边界 + 各引擎 docs 索引。各引擎详细边界/验收下沉到 `src/<引擎>/docs/`。

## 形态边界（已定）

- V1 = 纯在线 Web，**无离线能力**
- 离线需求后置，将来走原生 App，**不是 PWA**
- MVP **不接真实支付**（见 ADR-0001）：支付页 + 后端接口占位，触发链路已定
- 埋点/北极星分析通过 Analysis API **后置接入**，MVP 不实现（靠统一事件日志解耦）

## 全局验收要点

- 统一合约通过（`docs/合约.md` v0.3）
- 各引擎通过合约一致性测试 + 端到端跑通代表课
- 同一节课连续切换多引擎：**无二次登录、整页刷新、进度断裂**
- 中断恢复成功率 **≥ 99.5%**，已完成活动不回退
- 必修活动静默跳过 = **0**；原始路径/单元格/异常栈进入学习者界面 = **0**
- 测验题集、随机种子、内容版本、评分规则**可追溯**
- 格式型答案误判率 **< 0.5%**
- Course Studio 能从每个问题**定位回原 Excel 单元格或素材**
- 发布中的课程版本**不可原地覆盖**，支持快速回滚
- 登录、选课、答题、反馈、暂停、恢复**可完全键盘完成**
- 北极星指标 = 单位有效练习时间带来的 **7/30 日延迟保持率**（Analysis API 后置接入）
- 待决项见 `docs/OPEN-QUESTIONS.md`
