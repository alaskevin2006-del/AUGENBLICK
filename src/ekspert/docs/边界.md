# Ekspert 边界

> 本引擎边界由本引擎维护；跨引擎冲突报规划总控。共性约束见 `../../docs/baseline/README.md` + `ekspert.md`。

## 定位

多轴分类引擎：看图/示意图，在多个独立轴（物种/体征/时代…）同时判定。模块：动物足迹/牙齿/陶瓷/化石。

## 做什么

- 模块注册表驱动：新增模块 = 新增 JSON+SVG 目录，零改核心代码。
- schema：模块配置（axes 类型/值/axis_difficulty）+ 记录（axes/features/media/confuse_with/difficulty）+ 决策树。
- curated confusion（作者 `confuse_with`）与 observed confusion（Learning State 混淆矩阵）**分离**。
- 单轴 quiz / 多轴 quiz。

## 不做什么

- SM-2 间隔重复 / confusion matrix / mastery coefficient → 映射平台 L/T + Learning State。
- localStorage / SQLite 持久化 → 后端。

## 第三层数据结构

JSON（data.json / trees.json / svg/）。对编排器不透明，仅暴露 package / itemCount。

## Phase 范围（v1 = Phase 1）

- **Phase 1（MVP，V1 做）**：单轴+多轴 quiz、atlas 过滤、tracking（50 足迹）、teeth（5 种）、基础统计、SVG。
- **后置**：comparison、decision tree、spaced repetition、confusion matrix、ceramics、fossils、photo import、PWA/offline。

## 评分

各轴分数（dimensions[]），平台归一 0–1。

## 待澄清

Atlas/Comparison/Decision Tree 与平台 L/T + REVIEW 的映射（OPEN 登记）。
