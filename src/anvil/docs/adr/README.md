# Anvil 引擎内部 ADR

> 本引擎内部的架构决策记录。跨引擎 / 需客户拍板的决策**不写这里**，回报规划总控，由总控写根 `docs/adr/` 或 `docs/OPEN-QUESTIONS.md`（`docs/工作约定.md` 交接铁律 3）。

## 何时写

- 本引擎内部一个有争议、或影响后续实现的决策定型后。
- 典型：题型分型优先级树、第三层 Excel 模板定稿、0/1 vs 部分分、与 Znawca 的复用边界。

## 编号与命名

- 沿用根 ADR 编号体系，`NNNN-短横线标题.md`，从 `0001` 起（`0000` 为模板，不编号使用）。
- 模板见 `0000-adr-template.md`。

## 与根 ADR 的分工

| 层级 | 归属 |
|---|---|
| 跨引擎（合约 / 架构 / 技术栈 / 内容存放 / 学习测试判定） | 根 `docs/adr/`（唯一） |
| 仅 Anvil 内部 | `src/anvil/docs/adr/` |
