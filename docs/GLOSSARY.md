# 术语表（GLOSSARY）

> 全项目统一用词。所有引擎、文档、代码、对话必须用这里的叫法，不自行发明同义词。

## 核心术语

| 术语 | 定义 |
|---|---|
| 引擎 | 教学引擎（Znawca / Anvil / Ekspert / Sokole Oko / Companion 共 5 个 + **Direct 保留位**） |
| 运行时 | 浏览器环境（引擎运行的地方） |
| 内核 | Chromium |
| 学习操作系统 | AUGENBLICK 的产品定位（学习者看课程/进度/反馈，开发者看结构/校验/发布） |
| Polyglot / Savant | 同一软件的两个品牌站点：仅 logo、域名、内容目录不同；引擎与格式完全相同（ADR-0006） |
| 编排器 | 调度引擎、分发调用包、收集事件的平台组件 |
| 外壳 | 平台统一 UI（导航 / 登录 / 课程入口） |
| Activity Host | 统一宿主，承载各引擎活动（主题/尺寸/焦点/键盘/RTL/暂停/退出确认） |
| 引擎注册表 | 模块化单体中引擎的接入登记 |
| Course Studio | 课程开发者工作台（导入·校验·预览·评审） |
| Course Version | 不可变课程版本（规范化内容 + 资产清单） |
| Learning State | 学习状态（掌握度 / 错题 / 事件 / 分析） |
| 内容流水线 | 导入、校验、编译、版本、发布、回滚 |
| 后台 | 平台管理界面 |
| 平台腿 | 全新从零的平台侧（外壳 + 编排器 + 后端 + 内容流水线 + 后台） |
| 引擎腿 | 5 引擎侧（Znawca 复用内核，其余新写）+ Direct 保留位 |
| 切片 | 垂直切片：平台最小骨架 × 一个引擎，端到端跑通一节课 |
| REVIEW | B 列保留关键字，编排器指令：从学习者失败台账（Failed-Item Ledger）重放错题，非引擎（AUGENBLICK §6） |
| 至言 | AUGENBLICK / Polyglot 的历史旧称，双品牌定名后废弃，勿再使用 |

## 引擎合约术语（三份合约）

| 术语 | 定义 |
|---|---|
| 三份合约 | 内容编译合约 / 运行时合约 / UI 宿主合约 |
| 调用包 JSON | 编排器给引擎的统一输入 |
| 四事件 | activityReady / itemStarted / itemResolved / activityFinished（主里程碑，字段已扩展） |
| score | 评分，归一化 0-1 |
| dimensions[] | Ekspert 各轴 / Sokole 各区域 / Companion 音素·节奏·语调 |
| 适配器 | 引擎侧实现统一合约的接缝代码 |

## 内容模型

- 第一层：课程发现（xlsx）
- 第二层：课程脚本（xlsx，一行 = 一个活动，B 列指定引擎）
- 第三层：引擎数据（各引擎私有，对编排器不透明）
- Excel = 批量创作与交换格式；运行时读「不可变 Course Version」，不直接读 Excel

## 形态术语

- V1 = 纯在线 Web（无离线能力）
- 离线后置：将来走原生 App，不是 PWA
- MVP 不接真实支付（接口占位，见 ADR-0001）
- 北极星指标 = 单位有效练习时间带来的 7/30 日延迟保持率（Analysis API 后置接入）
