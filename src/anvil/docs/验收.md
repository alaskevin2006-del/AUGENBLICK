# Anvil 验收标准

## 完成标准（可量化）

- 通过合约一致性测试（`tests/contract`），四事件字段完整、可幂等重放（`eventId` / 顺序号 / 时间戳）。
- 9 题型全部可渲染：多选 / 矩阵 / 完形选择 / 完形填空 / 匹配 / 图文选择 / 持久媒体集 / 音频+图文（`requirements/Anvil.md §4`）。
- 端到端跑通一节代表课：载题 → 题型分型 → 作答 → 评分证据 → 事件回传。
- 评分归一验证：每题 `score` = 0 或 1（部分分不适用，见 `docs/待确认.md` B4）。
- 题型分型准确率：格式型误判率对齐全局 `< 0.5%`（`docs/边界与验收.md`）。
- 选项乱序：每次呈现选项位置随机（`requirements/Anvil.md §4`），使用编排器随机种子保证可追溯。
- 媒体播放：图片/音频/视频按单元格内容判定并从对象存储签名 URL 加载；旁白 `[Column][Row].mp3` 存在时显示喇叭图标（`requirements/Anvil.md §3`）。
- 校验降级：缺媒体 / 结构不符的题跳过并提示，不阻断整课加载（`requirements/Anvil.md §9`）；错误信息单元格级（如 "Cell A47 references 'robin.jpg'，未找到"）。
