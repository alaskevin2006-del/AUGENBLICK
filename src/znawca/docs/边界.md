# Znawca 边界

> 本引擎边界由本引擎维护；跨引擎冲突报规划总控。共性约束见 `../../docs/baseline/README.md` + `znawca.md`。

## 定位

抽认卡引擎：显示图（或文）→ 提问 → 作答 → 评分。学习/测试两模式。

## 做什么（含有效需求）

- 题型：文本输入 / 多选（列值 3 个用 3 按钮、≥4 用 4 按钮）/ 选图（4 选 1）/ 纯文本双向（item→属性、属性→item、双向）。
- 答案语法：
  - `;` 分号 = 多部分答案，任意顺序、全对才满分（部分对仍算错需重做）。
  - `/` 斜杠 = 可接受替代（由统一求值管线裁决，作者确认）。
  - `#` 列 = 仅筛选、永不出题。
- 筛选：`#` 列勾选 + AND 叠加；同值列自动跳过。
- 教学风格：strict（干扰项取自筛选范围）/ lenient（干扰项取自全库）。
- 单元格音频（喇叭图标）+ 正误反馈音（已由客户反馈确认）。
- 无图片子目录 → 自动纯文本模式。

## 不做什么

- 难度记忆 / 成绩历史 → Learning State。
- 界面语言（5 语言）→ Shell。
- 判分裁决 → 统一求值管线（引擎只交 0/1 证据）。

## 第三层数据结构

Excel（A 列 = item 名 = 图片子文件夹名；`#` 列 = 筛选；其余列 = 题干/答案）+ 图片子文件夹（item 名对应）。

## 复用

复用原 Znawca core（评分/抽题/会话状态机）+ 答题 UI；剥离 Electron 壳；loader 抽数据源接口；事件 pull→push。

## 评分

0/1（分号多答案全对 = 1，否则 0）。

## 待澄清

答案分隔符（`;` 必需 / `/` 可替代）与「一单元格多媒体」待平台统一（OPEN 登记）。
